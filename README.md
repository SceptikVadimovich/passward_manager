# Password Manager

Автор: Ягодаров Данила

## Краткое описание

Консольное приложение для безопасного хранения, генерации и управления паролями. Программа позволяет:

- Сохранять пароли для различных сервисов
- Просматривать список всех сохранённых паролей
- Искать пароли по названию сервиса
- Удалять устаревшие записи
- Генерировать случайные пароли с настраиваемыми параметрами
